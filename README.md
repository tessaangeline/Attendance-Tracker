# Attendance Tracker 🏢
> Frictionless daily attendance for small teams — push notification → one tap → done.

---

## How it works

**For employees**  
Every weekday at 9:00 AM, a notification pops up with two buttons:  
**✅ Present** · **🌴 On Leave**  
Tap one. That's it. No app to open. No login. Done in 2 seconds.

**For admins**  
Open the admin dashboard → see the full team, leave balances, and today's status in real time.  
Export a CSV or let it auto-sync to Google Sheets.

---

## Quick Start (First Time)

### 1. Install dependencies
```bash
cd Angeline_Task2
npm install
```

### 2. Generate your keys
```bash
npm run setup
```
This creates a `.env` file with your VAPID push keys and **admin secret**.  
> **Save the admin secret** — you'll need it to log in to the admin dashboard.

### 3. Start the server
```bash
npm start
```

### 4. Open the app
| Page | URL |
|---|---|
| Employee Registration | http://localhost:3000 |
| Admin Dashboard | http://localhost:3000/admin.html |

---

## Onboarding Employees

1. Open `http://localhost:3000`
2. Enter the employee's name → click **Get My Attendance Link**
3. Copy the generated link and send it to the employee (via WhatsApp, email, etc.)
4. Employee opens the link → taps **Enable Morning Reminders** → adds to home screen
5. That's it — they'll get a 9 AM notification every weekday

## Admin Dashboard Features

| Feature | How |
|---|---|
| Live team report | Open `/admin.html`, enter admin secret |
| See today's status | Table shows ✅ Present / 🌴 Leave / – Not marked |
| Leave balance per person | Remaining column (green = ok, red = used up) |
| Manual notification trigger | Click "🔔 Notify All" |
| Export to CSV | Click "⬇️ Export CSV" |
| Add employee from admin side | "Add Employee" card on dashboard |
| View employee calendar | Click "📅 View" on any row |

## Leave Rules
- Each employee gets **4 leaves per month**
- Weekends are **not counted** (bot never sends a notification on Sat/Sun)
- Unused leaves **do not carry over** — reset to 4 on the 1st of each month
- If an employee marks leave after using all 4, it's still recorded but **flagged as over-limit** (⚠️ shown in red on admin dashboard)

## Google Sheets Sync (Optional)

To have attendance automatically written to a Google Sheet:

1. Create a Google Sheet with two tabs: `Attendance` and `Summary`
2. Go to [Google Cloud Console](https://console.cloud.google.com) → create a Service Account
3. Download the credentials JSON file → save as `google-credentials.json` in this folder
4. Share your Google Sheet with the service account email
5. In `.env`, set:
   ```
   GOOGLE_SHEET_ID=your-sheet-id-from-url
   GOOGLE_CREDENTIALS_FILE=./google-credentials.json
   ```
6. Restart the server — attendance marks will now auto-fill the sheet

## Troubleshooting

**"VAPID keys missing" error on start**  
→ Run `npm run setup` first to generate your `.env` file.

**Notifications not arriving**  
→ Make sure the server is running and employees have clicked "Enable Morning Reminders" on their dashboard.  
→ Use "🔔 Notify All" in the admin dashboard to test immediately.

**Push not working on iPhone**  
→ iOS requires Safari 16.4+ and the PWA must be **added to home screen** for push notifications to work.  
→ On older iOS, employees can still mark attendance from the dashboard directly.

**"Wrong admin secret" on admin dashboard**  
→ Check your `.env` file for the `ADMIN_SECRET` value.
